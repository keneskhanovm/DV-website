## Technologies to use for web programming:
- **HTML5** for the page structure (headings, paragraphs, lists, sections).
- **CSS** in a dedicated file (`css/style.css`) for all styling, including SVG elements, which are styled with selectors and never inline.
- **JavaScript (vanilla)** for interactivity.
- **D3.js** to load data and draw the charts as SVG.
- **Git and GitHub Pages** to version the code and publish the site.

## Strategies/technologies to use for data handling/processing:
- **Python** with **pandas** to clean, filter and aggregate the datasets.
- **Jupyter Notebook** to document each step, so the processing is reproducible.
- **CSV or JSON files** produced by Python and stored in the repository, loaded into the charts with D3.
